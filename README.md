# CodeAlpha Internship - Frontend Development Tasks

This repository contains the completed frontend development tasks completed as part of the CodeAlpha Internship program. Each project is built using modern **HTML5**, **CSS3**, and vanilla **JavaScript**, featuring responsive designs and interactive user experiences.

---

## 🚀 Projects Overview

| Task | Project Name | Description | Key Features |
| :--- | :--- | :--- | :--- |
| **Task 1** | **Responsive Image Gallery** | A dynamic photo gallery with category-based filtering and an immersive preview mode. | • Category filtering (All, Nature, Architecture, etc.)<br>• Interactive Lightbox modal view<br>• Fully responsive grid layout |
| **Task 2** | **Advanced Calculator** | A sleek, feature-rich web calculator designed for precision and ease of use. | • Full keyboard support<br>• Clean mathematical operations interface<br>• Error handling & clear state management |
| **Task 3** | **Modern Music Player** | A full-featured audio streaming interface powered by direct public CDN MP3 streams. | • Live Bensound audio stream integration<br>• Rotating album art visualizer effect<br>• Play, pause, skip, repeat, shuffle controls<br>• Volume slider & interactive playlist drawer |

---

## 🛠️ Tech Stack

* **Markup:** HTML5
* **Styling:** CSS3 (Variables, Flexbox, CSS Grid, Custom Animations)
* **Scripting:** Vanilla JavaScript (ES6+)
* **Assets:** Unsplash API (Images), Bensound (Audio Streams)
